# AI-Based Smart City Management System

A Python project that demonstrates how AI techniques can support traffic monitoring and smart-city decision making. It combines ten small, educational modules with an interactive Streamlit dashboard.

> **Data note:** `data/traffic.csv` is synthetic data generated by this project. The models and demonstrations are for learning and are not intended for real-world traffic control.

## Features

- Interactive dashboard with traffic summaries, route comparisons, fuzzy signal controls, model results, reinforcement learning, vehicle detection, and robotics demonstrations.
- Traffic record explorer with filters and downloads, plus a local rule-based chatbot that answers questions about the dataset without external AI services.
- Ten AI modules covering agents, search, adversarial search, fuzzy logic, machine learning, neural networks, reinforcement learning, computer vision, robotics, and data science.
- Reproducible dataset generation and scripts that save charts and CSV results to `outputs/`.

## Getting started

Use Python and run these commands from the project directory:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run the complete set of demonstrations:

```powershell
python run_all.py
```

Start the dashboard:

```powershell
streamlit run app.py
```

Streamlit prints a local URL (typically `http://localhost:8501`) when the dashboard is ready. The dataset generator creates `data/traffic.csv` when needed; `run_all.py` regenerates it and refreshes the output charts and CSVs.

## Project modules

| Module | File | Topics |
|---|---|---|
| 1 | `m1_agents.py` | Reflex, model-based, goal-based, and utility-based agents |
| 2 | `m2_search.py` | BFS, DFS, UCS, and Vacuum World |
| 3 | `m3_adversarial.py` | Minimax and alpha-beta pruning |
| 4 | `m4_informed.py` | Greedy search, A*, hill climbing, TSP, 8-Queens, and 8-Puzzle |
| 5 | `m5_fuzzy.py` | Forward-chaining rules and fuzzy signal control |
| 6 | `m6_ml.py` | SVM classification and K-Means clustering |
| 7 | `m7_ann.py` | NumPy neural network with backpropagation |
| 8 | `m8_rl.py` | Q-learning traffic-signal control |
| 9 | `m9_cv_robotics.py` | Vehicle detection and A*-based emergency robot navigation |
| 10 | `m10_datascience.py` | Data cleaning, summary statistics, charts, and model comparison |

## Project layout

```text
app.py                 Streamlit dashboard
run_all.py             Run all demonstrations and refresh generated outputs
data.py                Generate and load the synthetic traffic dataset
m*.py                  AI module implementations
data/traffic.csv       Generated traffic dataset
outputs/               Example charts and CSV results
requirements.txt       Python dependencies
```

The viva handbook is intentionally not included in this repository. Generated Python cache files and the local run log are also excluded.
